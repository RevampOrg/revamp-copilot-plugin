# Revamp Website Builder for GitHub Copilot

Create or redesign a website, build a web app, and continue refining it with Revamp from GitHub Copilot. Describe the result you want in ordinary language; Revamp creates a project you can preview and improve in the same conversation.

## Connect

Install this plugin, then connect your Revamp account when Copilot prompts you. The plugin uses Revamp's hosted MCP server at `https://app.revamp.dev/mcp`. It contains no account credentials and runs no local server.

## Try it

- “Create a modern website for my law firm with practice areas, attorney profiles, and consultation requests.”
- “Redesign my website at [public URL] with a clearer message and an easier path to book a consultation.”
- “Build a client portal where customers can sign in and see their project updates.”
- “Show my recent Revamp projects.”

Revamp can start a project without opening a browser tab. Copilot can check its progress, show the latest available preview, and request changes to the same project. A preview is not a published website.

Learn more at [revamp.dev](https://revamp.dev/). For help, visit [Revamp support](https://revamp.dev/support/).
